\section{Objetivo}
Controlar un led rgb por medio de internet, para manipular cualquier color del led rgb y, encender y/o apagar cada color a distancia.

\section{Desarrollo de la Práctica}

\subsection{Condiciones de la Práctica}
Consiste en usar tres salidas, las cuales serán controladas desde una pagina web. Se deberá utilizar un Arduino y una shield wifi, ademas de un led rgb. Por lo tanto se deberá tener en dicha pagina tres perillas, una perilla dirá color rojo; la otra dirá color verde y, la última dirá color azul . Y de está manera encender cada uno de los colores del led rgb, con una intensidad diferente y, de esta manera ver en el led rgb, cualquier color; y todo controlado desde internet.


\subsection{Algoritmo o Diagrama de Flujo}

\begin{itemize}
  \item Inicializar comunicación serie.
  \item Conectar a la red WiFi con SSID y contraseña.
  \item Configurar canales PWM para los pines RGB.
  \item Iniciar servidor HTTP y registrar rutas ("/" y "/slider").
  \item Generar página HTML con sliders para R, G y B.
  \item En la ruta "/slider": leer parámetros (color, valor), actualizar variable y escribir PWM.
  \item Responder al cliente y continuar en loop (espera/idle).
\end{itemize}
